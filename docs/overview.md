# 项目概览

[文档目录](README.md) · [项目首页](../README.md)

<a id="核心能力"></a>

| 示教方式 | 场景与坐标系 | 主要用途 |
| --- | --- | --- |
| 地图示教 | 完整 PLY 场景，`map` 坐标系 | 规划机器人停车点、机械臂姿态及导航路径，组织完整场景中的示教任务 |
| 独立示教 | 局部 PLY 物体或工位，`virtual_origin` 坐标系 | 在局部空间完成示教，通过“示教转换”放入地图，或从地图提取区域后精调回写 |
| iPad AR 示教 | 独立示教物体，采集结果使用 `virtual_origin` | 按 1:1 比例放置虚拟物体，逐个记录相机 Pose，通过 AirDrop、Type-C 文件拷贝或局域网同步到电脑 |

| 能力 | 可以完成的工作 |
| --- | --- |
| 🤖 机器人姿态控制 | URDF 加载、底盘与全身关节调整、末端拖拽、相机反算、IK 锁定与姿态库 |
| 📝 示教任务管理 | 按“任务 → 停车点 → 机械臂姿态”组织数据，恢复姿态、回放任务、合并停车点 |
| 📷 视觉示教参考 | Zivid 2 M70 仿真视图、RGB / XYZ 快照与已示教区域显示 |
| 🗺️ 场景与导航 | PLY 点云 / 内嵌网格、Z 轴切片、二维导航点与有向路径编辑 |
| 🧰 模型编辑 | 调整 XYZ / RPY 坐标原点、裁剪 PLY 点云与网格、降采样或简化并导出 |
| 💾 工程保存与交换 | 独立工作区自动保存，完整工程目录、JSON / ZIP 导入导出与机器人数据导出 |

> **能力边界**：iPad 记录相机参考位姿，当前不自动求解机器人关节值；Zivid 画面与覆盖显示来自虚拟模型。机器人执行范围见[导出说明](robot-export.md#机器人示教数据导出)。

<a id="vision-pro-空间示教"></a>

## 🥽 Vision Pro 空间工作台

![Apple Vision Pro 设备示意](../images/vision-pro.png)

Vision Pro 启动后可 **选择设备同步** 电脑当前工程，也可 **载入当前工程 / 工程文件**。资源准备好后自动进入原生 RealityKit 全沉浸空间，以真实尺度在地图与机器人周围观察、游走。转头与小范围移动使用头部追踪；远处通过 **点选地面 → 前往此处** 跳转，也可在沙盘中选择位置。默认空间界面不需要数值或文字输入。

辅助面板提供沙盘、回放和 **编辑工具**，更多游走、测量和保存操作收进菜单。完整工程编辑器按需打开，保留 Mac 的地图、机器人、导航、任务、关节与末端、路径检查和 ZIP 导入导出能力；修改后选择 **更新空间** 更新原生场景。设备同步沿用电脑授权和双向工程协议，完整资源接收后可离线继续。iPad / iPhone 示教体验保持独立。

工程入口、能力边界、构建验证与真机联调见 [Vision Pro 开发文档](../vision/README.md)。历史单模型相机示教保留在首页的兼容入口。

Mac 上执行 `./scripts/run-vision-simulator.sh start` 启动模拟器，修改后执行 `./scripts/run-vision-simulator.sh start --rebuild`；用 `stop` 停止、`status` 查询状态。Xcode 构建时自动打包工作台页面和 Worker，需要先安装项目的 Node 依赖。

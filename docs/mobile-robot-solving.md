# 设备 Pose 转机器人姿态

[文档目录](README.md) · [项目首页](../README.md)

## 计算入口与流程

接收设备示教后，在右侧 **示教 → iPad / iPhone 示教、Vision Pro 示教** 切换来源。展开任务即可看到逐个采样 Pose；点击 Pose 会在 3D 中高亮采样位置、光学坐标轴和朝向，并显示待计算、可达待保存或已保存状态。移动端采样不需要停车点或机器人就能查看。

加载机器人并设置底盘支撑高度，在“采样 Pose”卡片或示教数据页的设备结果面板点击 **计算机器人姿态**。默认自动搜索底盘平面位置与朝向，优先复用合适的停车点，必要时每个 Pose 使用一个停车点。计算完成只保存计算报告；**可达 · 待保存** 表示尚未生成机器人示教任务。在计算完成卡片、右侧“采样 Pose”列表上方，或示教数据页的设备结果面板点击 **保存可达姿态**，即可生成停车点和对应机器人姿态并加入“示教数据”。关闭计算窗口或刷新页面后，仍可从后两个入口保存已有结果，无需重新计算。

**参考起始姿态**默认使用点击计算时的当前机器人姿态，也可选择当前机器人已保存的预设姿态。预设用于初始化计算副本的双臂、头部和躯干，并作为多初值搜索和候选解评分的参考，减少偏离期望构型的结果；后续动作仍兼顾连续性、目标容差和碰撞约束。受锁定约束的关节保留当前值（自动升降的三个俯仰关节按原规则处理），未包含在预设中的关节也保留当前值，底盘位置仍由停车点策略决定。选择参考不会直接移动工作台机器人或改写原始采样。报告保存参考名称、预设快照和实际初始关节值；更改选择后需重新计算，预设被删除或切换为其他机器人后需重新选择。

若同步后尚未加载机器人，可直接在计算窗口点击 **加载机器人** 并选择模型；原有采样和计算配置保留，模型就绪后 **开始计算** 自动启用。加载失败时窗口会显示具体原因，可重新选择模型重试，无需重新同步。若任务仅含轨迹采样点，取消勾选 **仅计算手动记录点** 后即可计算。

保存后右侧自动切换到 **电脑端示教**，展开对应停车点并选择姿态，点击 **调整选中姿态** 修改关节，最后在 3D 预览卡片中点击 **确认修改**。在来源采样详情中也可以点击 **打开机器人姿态**，直接找到对应的已保存姿态；**查看已保存任务** 会打开已有结果，保留精修内容，不重复生成任务。

这一步完成 Mac 端机器人动作精修。这里的移动端采集与 Vision Pro 历史单模型示教流程只交换相机参考 Pose，尚不支持回传或展示精修后的机器人关节动作。Vision Pro 的地图、机器人和任务同步见[完整工程模式](../vision/docs/project-workspace.md#启动与完整工程)。

- XYZ 分轴容差默认各 **5 cm**，Roll / Pitch / Yaw 分轴容差默认各 **5°**。XYZ 在工程坐标系中比较，角度按目标局部坐标系中的相对旋转以 ZYX 分解，避免 ±180° 回绕误判。
- 默认对齐**末端相机光学坐标系**，复现 iPad 的拍摄位置与方向；也可以选择 **tool 工具末端**，将位姿直接赋给该工具坐标系。计算会同时变换采样的位置与方向，支持经过 `mobileTransform` 放置的设备任务。
- **参考姿态偏好**默认选择“上半身优先 · 底盘配合”：优先接近参考的双臂、胸部转向及头部关节，踝、膝、腰俯仰用于升降与扶正；底盘移动与转向不计入上身参考偏差。由参考相机的完整位置和旋转反推停车点，再尝试左右转向、横移及原有通用候选，垂直拍摄也可用相机滚转确定底盘朝向。优先使用参考初值并比较上身偏差，减少对上一动作及停车点复用的偏重。可切回“全身姿态与动作连续性”。参考为软偏好，不覆盖关节锁定、限位、相机容差或碰撞要求。
- **停车点策略**提供“自动搜索 · 避让躯干并复用停车点”“每个 Pose 独立停车”“固定当前停车点”。自动/独立停车默认采用**水平地面 · 底盘自动调平**：当前 Z 作为支撑高度，Roll / Pitch 归零，搜索 X、Y 与朝向。也可选择**沿用当前高度与倾斜**，通过完整旋转矩阵绕工程 Z 轴转向。水平模式是显式的地面假设，不自动识别工件扫描中的地形；固定停车点始终保留当前完整底盘位姿。相机的位置、朝向和滚转始终保持采样目标，底盘不通过悬空升降来满足相机目标。结果逐点记录实际停车位姿，分别用于虚影、应用、保存及回放。
- 自动停车先满足躯干避让间距，再比较关节姿态。上半身优先模式依据参考相机与目标的匹配程度排列候选，允许增加停车点来减少上身变化；姿态相近时鼓励覆盖更多目标及双臂配合。全身连续性模式优先复用有余量的停车点、覆盖更多目标。搜索包含参考姿态对应的位置与朝向、当前停车点附近的调整，以及相邻目标之间的停车点。对附近最多 8 个 Pose 前瞻，找到有余量的姿态后比较最多 4 个可行停车点；否则继续搜索有限候选。每个目标只分配给一个相机，另一侧仍可作为不可达或余量不足时的后备。
- 同一停车点的左右目标优先组成**双臂同步动作**：联合求解两台相机的位置和朝向，共用同一组躯干关节，并检查完整机器人姿态的碰撞、前胸垂直和关节限位。每次最多尝试 3 个配对目标，也会从尚未处理的采样中寻找另一侧目标，避免“先记录完左侧，再记录右侧”的采样顺序强迫串行执行。两个目标无法同时满足时保留可达的单臂动作；独立停车模式不跨停车点配对。
- 多初值逆解在相机目标之外加入躯干间距和自身干涉的避让方向，并在满足容差后比较间距余量、关节连续性、与初始姿态的偏差和接近限位的程度。到达限位的关节会退出当前迭代方向计算，其他关节继续求解。双臂组合使用联合逆解的同一份全身关节值，不直接拼接两个独立解。
- 默认开启**碰撞筛选**：机器人检测体优先使用 URDF collision，缺少时使用可视模型包围盒；包括底盘、非相邻连杆自身干涉、工件及支撑平面。允许相连关节及共用中心的手腕/肘部外壳接触。工件网格索引完整三角面并检查闭合物体内部，点云检查现有点；检测体或工件缺失会停止计算并说明原因。包围盒为保守近似，点云或未闭合扫描面不能证明未观测空间无障碍。结果详情显示筛选状态与干涉部件。
- 碰撞筛选中新增**躯干避让间距**，默认 **5 cm**（可设 0–30 cm；0 仅检查相交）。对上臂活动段、肘部、前臂及相机与躯干、头部、底盘等非相邻检测体施加硬下限，额外争取约 3 cm 余量。距离采用有向包围盒投影分离量的保守下界，不是实测外壳距离。肩部两级外壳与自身安装座、支撑胸部连杆的固定安装间隙不套用该缓冲，但保留原相交检查；其他部位不豁免。闲置手臂的未锁定关节也可避让，单臂与双臂同步解均检查完整机器人。关闭碰撞筛选同时关闭间距约束；固定停车点或锁定关节无法满足时，该点不通过，不会降低间距标准。报告展示双臂间距下界及受限部件。
- 默认启用**自动调节胸部高度**，BOTX 的踝、膝、腰三个俯仰关节协同升降；即使它们在工作台中锁定，计算时也允许这三个关节参与。搜索先将胸甲扶正，并使用站立至下蹲的多种初值；底盘支撑高度不变。升降开启时强制保持**前胸垂直锁定**，以 `waist_yaw_L` 胸部向上轴与世界 Z 轴的夹角衡量，允许 yaw。**前胸垂直容差**独立于相机 XYZ / RPY 容差，默认 0.25°，可显式调整（大于 0°，不超过 10°）；底盘侧倾可能无法由三个俯仰关节补偿。腰部 yaw、机械臂等其他关节仍遵守当前锁定，所有 URDF 关节限位始终生效。旧版报告始终按当时的 0.25° 判定，修改容差需要重新计算。
- **遵守当前关节锁定**及**仅计算手动记录点**默认开启。关闭自动升降后，三个躯干俯仰关节重新遵守工作台锁定；关闭“遵守当前关节锁定”则允许其他关节也在限位内参与求解。
- 默认选择 **双臂分工 · 每个姿态只需一台相机**，也可限制为仅左臂或仅右臂。结果显示左右臂各自负责的目标数量、总动作组数及双臂同步组数，逐点标明“执行”和动作组；同组的两个目标由两台相机分别执行。无需重复求解的另一侧显示“未分配”。
- **参与求解**新增 **双臂协同 · 优先共用停车点**：在满足相机容差、关节限位、前胸垂直与碰撞要求后，优先选择两臂都能承担拍摄目标的底盘位；上半身优先时，继续以参考偏差为主要评分，并兼顾覆盖数量和分工。停车候选同时考虑左右参考相机与两个目标的匹配，尝试兼顾两侧的位置和朝向；同一停车点优先尝试任务较少的一臂。能联合求解时组成双臂同步动作，否则允许在同一底盘位依次拍摄，或保留只有一臂可达的结果。每个采样仍只拍摄一次，不要求两臂重复到达同一目标。自动搜索比较最多 8 个可行候选（满足整组覆盖及分工时可提前结束），属于有限搜索；上半身参考仍参与评分，但协同模式可为共用停车点接受更大的参考偏差。固定停车不改变底盘，“每个 Pose 独立停车”不跨目标协同。报告显示双臂参与与单臂参与的停车点数量；第 1–9 版报告保留原参与模式，选择新模式后需重新计算。
- 点击 **开始计算** 后配置窗口自动收起，回到 3D 工作台；求解在独立 Web Worker 中使用运动学副本，计算期间仍可旋转、缩放视图，不改变当前机器人。右上角进度面板显示完成数、可达数、未通过数和当前求解的姿态/机械臂。
- 计算完成后，在完成卡片或结果窗口点击 **动态预览**，即可按停车点和动作组顺序循环播放本次可达结果。双臂组只生成一段全身关节运动，两侧在同一条时间曲线上同时出发、到达各自目标；使用与“示教数据 → 播放任务”相同的播放器，支持暂停、调速、跟随和停止。预览无需先保存，也不会新增示教任务；没有可达姿态时按钮禁用。重新计算会停止预览，新一轮完成后可预览新结果。
- 每完成一个满足约束的采样点，即在该点求得的停车位置显示青色半透明机器人虚影、底盘标记和距离辅助线。默认跟随最新可达姿态（单次显示一个虚影），可用前后按钮回看，也可隐藏虚影或重新开启“跟随最新”。虚影、动态预览和保存使用同一个相机分工方案，已显示的姿态不会被后续分组更改。
- 进度面板支持 **暂停 / 继续**、**取消** 和 **重新计算**。暂停保留当前进度与预览；取消清除本轮预览并保留上次完整报告；重新计算以当前机器人位置、关节状态和本轮配置从头开始。切换工程、机器人或变更源采样后，本轮计算自动结束。计算期间切换到数据页仍可通过浮动面板控制。
- 计算期间点击 **计算详情**，在原弹窗右侧实时查看本轮逐条结果，包括可达性、六轴误差、胸部坐标系距支撑平面的高度、前胸倾角及未通过原因。暂停时保留已完成的条目，继续后追加；全部完成时窗口自动呈现完整的 **查看结果** 内容，并保留当前选中的条目。关闭窗口不影响后台任务，提交新配置会替换当前计算；未完成的结果仅供查看，完成后才可应用、预览、保存或导出报告。配置与报告不一致时需重新计算才能应用或保存。
- 结果显示实际计算时间、本次报告的参考偏好、地面支撑、升降开关及停车位姿的完整 RPY。每个解显示上半身旋转关节相对参考的平均绝对角度偏差（不含轮组及三个升降俯仰关节）。**导出计算报告**可单独保存源采样、坐标变换、计算配置、初始关节值与逐点失败原因，全部未通过时也可导出，用于按实际工程状态复现问题；工件几何仍通过工程 ZIP 导出。第 1–8 版报告保留原底盘和姿态评分含义；打开配置后默认采用新的上身优先与水平地面设置，需重新计算后生效。
- 未通过的机械臂在详情顶部列出具体原因：逐轴误差与本次计算容差、前胸倾角与本次设置的上限、自身/工件干涉部件、低于支撑平面或躯干间距不足。BOTX 底盘侧倾导致的前胸最小倾角仍超限时，说明俯仰关节无法补偿及可调整的设置。XYZ / RPY 全部达标但其他约束失败时单独提示；尚未执行的碰撞检查不视为已通过。误差格与求解器使用相同判定阈值，临界值自动增加小数位，悬停可查看原始误差。旧报告优先根据已保存数值补充提示，缺少诊断数据时提示重新计算。
- **应用左/右臂解** 或 **应用双臂解** 将该动作的全身关节及停车位姿恢复到虚拟机器人。**保存可达姿态** 创建普通示教任务，按停车点和规划的动作顺序分组；双臂组保存为一条全身姿态，同时保留左右光学目标和两个原始采样 ID，两条来源采样均能打开同一个可精修机器人姿态。自动或固定停车可将非相邻采样配对；“每个 Pose 独立停车”保留采样顺序并逐点创建停车点。原始设备采样顺序不变。未通过的点仅保留在报告中，不进入生成任务。
- 原始设备记录保留，报告及生成任务随工程自动保存、刷新恢复及 JSON/ZIP 导出；同一报告重复保存会打开已生成任务。坐标转换后旧计算报告失效，需重新求解。
- 第 1–4 版报告继续保留原动作，需重新计算才能生成双臂同步组，不会直接合并未经联合检查的旧解。第 3–5 版报告保留原升降开关；更早的报告打开配置时启用自动胸部升降，固定停车点旧报告还会默认选择自动停车与碰撞筛选。第 1–5 版报告不声明已通过躯干间距检查；打开配置会默认启用 5 cm 间距，需重新计算后应用新结果。数值逆解、配对和停车候选搜索都有预算，不保证全局最少停车点或最多配对，“未找到解”不代表数学上证明不可达。结果是静态姿态筛选，尚未验证停车点间导航路径、支撑面的实际可通行性或连续关节运动。
